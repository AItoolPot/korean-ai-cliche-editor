# korean-ai-cliche-editor

한국어 글에서 생성형 AI가 반복해서 쓰는 표현과 구성을 찾아 고치는 Claude 스킬입니다.

## 점검 항목

- 내용 중복: 도입·전개·정리에서 같은 주장이 되풀이되는 부분
- 구성 틀: 공감 질문 훅, 효과 약속, 출처 없는 일화·연구 인용, 반복 요약, 행동 촉구 등
- 표현: 과장된 대비·반전, '무너진다'류 은유 동사, '손에 남는 건'류 결론구, 번역 은유, 과장 어휘, 서식 남용 등
- 영상: 내레이션 대본, 화면 자막, 제목·썸네일 문구

맞춤법·띄어쓰기·문법은 다루지 않습니다. 이 점검에는 별도의 교정 스킬을 함께 쓰는 것을 권합니다.

## 적용 시점

내용을 수정하는 동안에는 적용하지 않습니다. 내용이 확정된 시점에 한 번 적용합니다.

- 사용자가 "확정", "최종본"이라고 말할 때
- 문서 파일 생성, 음성 합성, 영상 렌더링 직전

확정 후 일부를 수정하면 바뀐 부분만 다시 점검합니다.

## 설치

`korean-ai-cliche-editor` 폴더를 Claude의 스킬 폴더에 넣습니다. Claude Code에서는 `~/.claude/skills/` 아래에 둡니다. claude.ai에서는 폴더를 zip으로 압축해 스킬로 업로드합니다.

## 제한 사항

- 표의 예시는 점검 후보입니다. 단어가 나왔다는 이유만으로 자동 치환하지 않습니다.
- 이 스킬은 AI 작성 여부를 판정하지 않습니다. AI 탐지 회피 효과도 보장하지 않습니다.
