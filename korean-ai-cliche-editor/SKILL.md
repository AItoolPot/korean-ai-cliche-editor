# 한국어 AI 상투 표현 교정

한국어 글에서 생성형 AI가 반복해서 쓰는 내용, 표현, 구성 틀을 찾는다. 찾은 부분을 평이한 서술과 용도에 맞는 구성으로 고친다.
맞춤법·띄어쓰기·문법은 `korean-copyeditor` 스킬이 담당한다. 이 스킬은 내용 중복, 수사, 어휘 선택, 글의 전개 틀을 다룬다.

## 적용 시점

- 사용자가 AI 말투, 클로드 말투, 상투 표현의 점검을 요청할 때.
- 내용이 확정되어 문서·슬라이드로 만들기 전.
- 영상을 만들 때. 내레이션 대본, 화면 자막, 화면 텍스트, 제목·썸네일 문구가 대상이다.
- Claude가 사용자용 글을 직접 쓸 때도 아래 패턴을 피한다.

적용 순서는 이 스킬 → `korean-copyeditor` → 문서 생성·음성 합성·렌더링이다.

내용을 수정하는 중에는 이 스킬을 적용하지 않는다. 확정 시점에 한 번 적용한다. 확정 시점은 다음과 같다.

- 사용자가 "확정", "최종본"이라고 말할 때.
- 문서 파일 생성, 음성 합성·녹음, 영상 렌더링 직전.

확정 후 일부를 수정하면 바뀐 문단이나 장면만 다시 점검한다. 전체를 다시 점검하지 않는다.

## 판단 원칙

- 한두 번의 사용은 지적하지 않는다. 반복되거나 내용 없이 효과만 노린 경우에 지적한다.
- 단어만 보고 자동 치환하지 않는다. 문맥에서 기능을 판단한다.
- 글자 그대로의 뜻이면 유지한다. 예: '건물이 무너졌다', '센서가 작동한다'.
- 사용자가 요청한 수사, 직접 인용, 고유명사, 수업 발문은 유지한다.
- 원문의 사실·수치·조건·가능성·강조 대상을 바꾸지 않는다.
- 원문에 없는 내용이나 감정을 넣지 않는다.
- 이 패턴을 근거로 AI 작성 여부를 판정하지 않는다. 탐지 회피 효과를 약속하지 않는다.

## 내용 중복 점검

생성형 AI 글은 분량이 많아도 도입·전개·정리가 같은 내용을 되풀이하는 경우가 많다. 같은 상투 표현도 각 부분에서 반복된다. 이 점검을 가장 먼저 한다.

1. 문단마다 핵심 주장을 한 줄로 요약한다.
2. 같은 주장을 묶는다. 각 묶음이 몇 번, 어느 위치에 나오는지 적는다.
3. 같은 표현이 여러 부분에 반복되는지 확인한다.
4. 각 부분에 다음 역할만 남긴다.
   - 도입: 다룰 주제와 범위.
   - 전개: 근거, 사례, 절차, 세부 사항. 문단마다 새 정보가 있어야 한다.
   - 정리: 결론 한 번, 구체적인 다음 단계. 앞 내용을 다시 설명하지 않는다.
5. 새 정보가 없는 문단은 삭제나 병합을 제안한다. 줄어드는 분량을 함께 알린다.

강조를 위한 의도적 반복, 긴 보고서의 요약, 수업의 요점 확인 활동은 유지한다.
교안의 도입·전개·정리 단계 구분은 수업 설계 형식이므로 유지한다. 각 단계 안의 내용만 점검한다.

## 표현 패턴

표의 예는 점검 후보다. 목록에 없어도 같은 기능의 표현이면 점검한다.

| 패턴 | 예 | 수정 방향 |
|---|---|---|
| 과장된 대비·반전 | 'A가 아니라 B다', '단순한 A가 아닌 B', 'A? 아니다.', '사실은', '놀랍게도', '역설적으로' | B만 직접 서술한다. 실제 비교·정정이 내용이면 유지한다. |
| 극적 은유 동사 | '무너진다', '녹아든다', '스며든다', '선명해진다', '판이 바뀐다' | 실제로 일어난 변화를 구체적으로 쓴다. |
| 여운형 결론구 | '손에 남는 건', '결국 남는 것은', '이제 질문은 ~다', '답은 의외로 단순하다' | 결론 내용을 평서문으로 바로 쓴다. |
| 단정형 마무리 | '그거면 충분하다', '그게 전부다', '~하는 순간 달라진다', '이건 결국 ~의 문제다' | 근거와 함께 결론을 쓴다. 근거가 없으면 삭제를 제안한다. |
| 번역 은유 | '이 방식이 작동한다', '해상도 높게 보면', '~라는 렌즈로 보면', 'A와 B 사이의 긴장', '정직한 데이터', '조용히 바뀌고 있다' | 한국어 일반 어휘로 바꾼다. 예: '효과가 있다', '자세히 보면', '~의 관점에서', '충돌', '정확한 데이터', '서서히 바뀌고 있다'. |
| 감각·물성 어휘 | '결이 다르다', '단단한 구조', '질감', '온도', '무게', '생각의 근육' | 대상의 실제 속성을 쓴다. 예: '성격이 다르다', '안정적인 구조'. |
| 공간 은유 | '이 지점에서', '한 겹 더 들어가면', '층위', '공간을 만든다', '여백을 둔다', '한 발 물러서서 보면' | '이 부분에서', '더 자세히 보면', '수준', '기회를 준다'처럼 직접 쓴다. |
| 과장 어휘 | 혁신적, 획기적, 게임 체인저, 패러다임 전환, 여정, 핵심 열쇠, 강력한, 완벽한 | 구체적 사실이나 수치로 바꾼다. 근거가 없으면 삭제를 제안한다. |
| 추상 명사 결론 | '본질은', '핵심은', '~의 의미', '~라는 점에서 의미 있다' | 무엇이 왜 중요한지 구체적으로 쓴다. |
| 메타 도입 | '~에 대해 알아보겠습니다', '결론적으로', '요약하자면' | 내용으로 바로 시작한다. |
| 도입 상투구 | '흥미로운 건', '솔직히 말씀드리면', '정확히 짚으셨어요', '좋은 질문입니다' | 삭제하고 본론으로 시작한다. |
| 수사 의문문 | '왜 그럴까요?', '~라면 어떨까요?' | 답을 평서문으로 쓴다. 수업 발문은 유지한다. |
| 상투 비유 | '마치 ~와 같습니다', '~의 나침반/엔진/지도' | 비유 없이 대상을 설명한다. |
| 균형 상투구 | '물론 ~도 있지만', '~뿐만 아니라 ~까지'의 반복 | 실제 단서·예외만 남긴다. |
| 습관적 3개 나열 | '빠르고, 정확하고, 안전한'이 문단마다 반복 | 근거가 있는 항목만 남긴다. |
| 극적 끊기 | 한 줄 문단 연속, '그리고. 모든 것이 바뀌었다.' | 문장을 이어 정보 흐름을 만든다. |
| 서식 남용 | 줄표(—) 삽입구, '제목: 부제' 반복, 굵은 글씨 과다, 이모지 머리표 | 쉼표·괄호·문장 분리로 바꾼다. 강조는 꼭 필요한 곳만 남긴다. |

## 구성 패턴

도입·전개·정리에서 자주 보이는 틀이다. 섹션마다 같은 틀이 반복되거나, 틀이 내용보다 앞서는 경우에 지적한다.

| 위치 | 패턴 | 예 | 수정 방향 |
|---|---|---|---|
| 도입 | 공감 질문 훅 | '~해 본 적 있나요?', '혹시 ~라고 느낀 적이 있다면' | 다룰 주제와 목적을 바로 밝힌다. |
| 도입 | 통념 뒤집기 | '많은 사람이 ~라고 생각한다. 하지만…' | 주장과 근거를 바로 쓴다. 실제 오해를 바로잡는 글이면 유지한다. |
| 도입 | 효과 약속 | '이 글을 읽고 나면 ~하게 될 것이다' | 글이 다루는 범위만 쓴다. |
| 도입 | 출처 없는 일화 | '한 CEO는…', '어느 날 한 학생이…'로 시작 | 실제 사례면 출처를 밝힌다. 출처가 없으면 삭제를 제안한다. |
| 전개 | 섹션 틀 반복 | 모든 소제목이 주장 → 일화 → 교훈 순서 | 항목마다 내용에 맞게 구성한다. 일화가 필요 없는 항목에서는 뺀다. |
| 전개 | 법칙·단계 명명 | '성공의 3원칙', '5단계 법칙' | 실제 순서가 있을 때만 번호를 붙인다. 이름만 붙인 틀은 풀어 쓴다. |
| 전개 | 출처 없는 연구 인용 | '한 연구에 따르면', '전문가들은 말한다', '하버드 연구팀은' | 출처를 확인해 밝힌다. 확인하지 못하면 삭제하거나 '확인 필요'로 표시한다. |
| 전개 | 섹션 끝 교훈 한 줄 | 소제목마다 '기억하자, ~'식 마무리 | 반복되면 삭제를 제안한다. |
| 전개 | 독자 호명 반복 | '당신은', '여러분도'가 문단마다 등장 | 용도에 맞는 곳에만 남긴다. |
| 정리 | 반복 요약 | 본문 항목을 그대로 다시 나열 | 새 정보가 없으면 삭제를 제안한다. 긴 보고서의 요약은 유지한다. |
| 정리 | 행동 촉구 | '오늘부터 시작하라', '지금 바로 첫걸음을' | 구체적인 다음 단계가 있으면 그것만 쓴다. |
| 정리 | 격려·확신 | '당신은 이미 준비가 되어 있다' | 삭제를 제안한다. |
| 정리 | 수미상관 회귀 | 처음 일화나 질문으로 되돌아가 마무리 | 내용 없는 반복이면 삭제를 제안한다. |
| 정리 | 여운 질문 | '당신의 다음 선택은 무엇인가?' | 결론을 평서문으로 맺는다. 토론 과제·발문이면 유지한다. |

용도별 기본 구성은 다음과 같다. 사용자가 구성을 지정하면 그 구성을 따른다.

- 보고서·제안서: 결론 → 근거 → 세부 사항 → 다음 단계.
- 설명서·안내문: 목적 → 절차 → 주의 사항.
- 강의 대본·영상 대본: 주제 제시 → 내용 → 요점 확인. 훅은 내용과 직접 관련된 사례·질문일 때만 쓴다.

## 영상 적용

- 내레이션은 구어체를 유지한다. '~거든요', '~죠' 같은 구어 어미는 상투 표현이 아니다.
- 장면마다 핵심 주장을 하나만 둔다. 여러 장면에 같은 주장이 반복되면 병합을 제안한다.
- 첫 장면의 훅은 내용과 직접 관련된 사례·질문·수치일 때만 쓴다. 공감 질문 훅과 효과 약속은 점검한다.
- 마지막 장면은 결론과 다음 단계만 둔다. 앞 장면 내용을 다시 설명하지 않는다.
- 화면 자막, 제목, 썸네일 문구도 표현 패턴을 점검한다. '충격', '완벽 정리', '이것만 알면' 같은 과장 문구를 확인한다.
- 사용자가 요청한 채널 고정 문구(인사, 구독 안내 등)는 유지한다.
- 수정으로 장면 길이가 바뀌면 장면별 변경 시간(초)을 함께 알린다.

## 절차

1. 글의 용도, 독자, 문체(서술식·개조식·구어체)를 파악한다. 영상이면 장면 단위로 나눈다.
2. 내용 중복을 점검한다. '내용 중복 점검' 순서를 따른다.
3. 구성을 점검한다. 섹션별 틀을 나란히 놓고 비교한다.
4. 표현을 점검한다. 표현 패턴을 찾고 같은 패턴의 반복 횟수를 센다.
5. 지적한 부분마다 수정안을 만든다. 원문의 뜻과 말투를 유지한다.
6. 수정본을 원문과 대조한다. 의미 변화, 새 상투 표현, 정보 누락을 확인한다.

## 결과 제시

- 내용 중복: `주장 | 등장 위치 | 남길 위치 | 처리` 표로 제시한다.
- 표현 점검: `위치 | 원문 | 수정안 | 패턴 | 이유` 표로 제시한다. 반복 패턴은 한 행으로 묶고 횟수를 적는다.
- 구조 수정: 문단 단위로 위치와 수정 방향을 제시한다. 섹션 삭제·재배치는 계획을 먼저 보이고 승인 후 반영한다.
- 문서 작성 과정의 표현 수정: 수정을 본문에 반영한다. 바꾼 부분은 대화에서 짧게 알린다.
- 의미가 바뀔 수 있는 수정: 본문에 반영하지 않고 '확인 필요'로 따로 표시한다.
- 상투 표현이 없는 글: 수정할 부분이 없다고 짧게 알린다.
